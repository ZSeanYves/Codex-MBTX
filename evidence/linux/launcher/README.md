# Linux launcher evidence

`moon run scripts/collect-linux.mbtx evidence/linux/launcher/<run-id>` writes
the local Shell versus Transparent MBTX launcher comparison here. This data
does not require a model or relay credential.

The [release startup study](20260914T044744-1789332464819/report.md) uses
spawn-to-ready timing and separate minimal/full observation groups. The
[earlier debug comparison](20260913T055354901398588/report.md) uses a different
measurement boundary and must not be pooled with it. See the
[evaluation report](../../../docs/reports/linux-evidence-review-2026-09-14/README.md)
for interpretation and confidence intervals.
