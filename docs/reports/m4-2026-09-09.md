## 已验证的能力与发现

MBTX 在六类任务上都至少有一次完整通过，包括 JSON/JSONL、特殊路径、
字面量 argv、函数修复、后台执行与 `job_output` 轮询。后台任务记录了
`background_runs=1`、`job_output=1`，结果正确。实际调用中没有 shell 回退，
说明它可以接入 Codex 的工具循环并保留此次覆盖的任务管理能力。

本批次记录了 51 次 `mbtx` 调用，13 次 `script_exit`，零次 `runner_error`。
保留诊断主要是模型生成代码时遗漏 async 导入、使用错误的 Map 遍历语法、
误加 `mut`、调用不存在的 API 等。即使提供通用参考，MoonBit 脚本生成仍有
额外纠错开销；后续应改进可执行模板与 API 发现，再另起一批固定配置评测。

本次真实执行还修复了两个工程问题：

1. 判分控制器把 `Some(file_text)` 编码成 `[file_text]`，使正确文件被误判。
   现显式编码为字符串或 null，CLI 对非法包装直接报证据协议错误，
   回归检查覆盖正确、缺失和旧数组包装三种情况。
2. MoonBit 成功编译时可能输出多条警告 JSON，再输出产物 JSON。
   运行器原先按单份 JSON 解析；现按行读取并将警告保留到 stderr。
   带警告的合法脚本已有实际执行回归测试。
